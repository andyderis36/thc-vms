# PANDUAN PENGEMBANGAN LOKAL & SEED DATA (LOCAL_DEV.md)
# Project: THC Visitor Management System (VMS) - ISP Edition
# Versi: 3.1.0 (September 2026 LTS Tech Stack)

Dokumen ini adalah panduan teknis operasional untuk menyiapkan lingkungan pengembangan lokal (*local development environment*), menjalankan dependensi container (PostgreSQL & MinIO), menjalankan migrasi database, mengisi data awal (*seed data*), serta menjalankan backend dan frontend.

---

## 1. PRASYARAT SISTEM (*PREREQUISITES*)

Pastikan perangkat lokal telah terinstal:
- **Go**: Versi `1.26 LTS` atau `1.27.1` ([Download Go](https://go.dev/dl/))
- **Node.js**: Versi `22 LTS` (disertai `npm` atau `pnpm`) ([Download Node.js](https://nodejs.org/))
- **Docker & Docker Compose**: Docker Desktop atau Docker Engine aktif ([Download Docker](https://www.docker.com/products/docker-desktop/))
- **golang-migrate CLI** (opsional untuk migrasi CLI manual):
  ```bash
  go install -tags 'postgres' github.com/golang-migrate/migrate/v4/cmd/migrate@latest
  ```

## 3. FILE KONFIGURASI DOCKER COMPOSE

File `docker-compose.yml` disiapkan di root proyek untuk mempermudah orkestrasi:

```yaml
version: '3.8'

services:
  postgres:
    image: postgres:18-alpine
    container_name: thc-vms-postgres
    restart: always
    environment:
      POSTGRES_USER: thc_user
      POSTGRES_PASSWORD: thc_password_local
      POSTGRES_DB: thc_vms_db
    ports:
      - "5432:5432"
    volumes:
      - pgdata_local:/var/lib/postgresql/data
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U thc_user -d thc_vms_db"]
      interval: 5s
      timeout: 5s
      retries: 5

  minio:
    image: minio/minio:latest
    container_name: thc-vms-minio
    restart: always
    command: server /data --console-address ":9001"
    environment:
      MINIO_ROOT_USER: minioadmin
      MINIO_ROOT_PASSWORD: minioadmin
    ports:
      - "9000:9000"
      - "9001:9001"
    volumes:
      - miniodata_local:/data

  minio-init:
    image: minio/mc:latest
    container_name: thc-vms-minio-init
    depends_on:
      - minio
    entrypoint: >
      /bin/sh -c "
      /usr/bin/mc alias set localminio http://minio:9000 minioadmin minioadmin;
      /usr/bin/mc mb localminio/thc-vms-bucket --ignore-existing;
      /usr/bin/mc anonymous set download localminio/thc-vms-bucket;
      exit 0;
      "

volumes:
  pgdata_local:
  miniodata_local:
```

## 5. URUTAN MENJALANKAN SISTEM (*STEP-BY-STEP RUNBOOK*)

### Langkah 1: Jalankan Database & Object Storage
```bash
docker compose up -d
```
*Tunggu beberapa detik hingga PostgreSQL siap dan bucket `thc-vms-bucket` terbuat otomatis oleh container `minio-init`.*

### Langkah 2: Jalankan Migrasi Skema Database
Dari direktori `backend/`:
```bash
# Menjalankan seluruh script SQL up
migrate -path migrations -database "postgres://thc_user:thc_password_local@localhost:5432/thc_vms_db?sslmode=disable" up
```
*Atau, backend Go Clean Architecture dapat mengeksekusi migrasi otomatis saat startup pada mode `APP_ENV=local`.*

### Langkah 3: Eksekusi Database Seeder
Dari direktori `backend/`:
```bash
go run seeds/main.go
```
*Perintah ini akan memasukkan akun master, daftar lokasi cabang/POP, dan tujuan kunjungan ke PostgreSQL.*

### Langkah 4: Jalankan Backend Server
Dari direktori `backend/`:
```bash
go run cmd/server/main.go
```
*API siap melayani request di `http://localhost:8080/api/v1/health`.*

### Langkah 5: Jalankan Frontend Next.js
Dari direktori `frontend/`:
```bash
npm install # atau pnpm install
npm run dev # atau pnpm dev
```
*Aplikasi web dapat diakses melalui browser di `http://localhost:3000`.*

Untuk memverifikasi MinIO berjalan dan menerima berkas:
1. Buka browser: `http://localhost:9001`
2. Login: `minioadmin` / `minioadmin`.
3. Periksa apakah bucket `thc-vms-bucket` sudah ada pada menu **Buckets**.
4. Test upload berkas sederhana:
   ```bash
   curl -F "file=@sample.pdf" http://localhost:8080/api/v1/uploads
   ```
   *(Harus mengembalikan URL absolut berkas di MinIO).*
