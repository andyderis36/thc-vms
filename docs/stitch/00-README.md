# Stitch Docs – THC Visitor Management

Folder ini berisi dokumentasi untuk generate UI di Google Stitch.

## Struktur Folder

```text
docs/stitch/
├── 00-README.md
├── 01-screen-inventory.md
├── 02-design-system.md
├── 03-user-flow.md
├── 04-screen-specs-internal.md
├── 05-screen-specs-external.md
└── 06-prompt-templates.md
```

## Urutan Pakai

1. Baca `01-screen-inventory.md` untuk daftar halaman.
2. Baca `02-design-system.md` untuk style guide.
3. Baca `03-user-flow.md` untuk navigasi.
4. Pakai `04-screen-specs-internal.md` & `05-screen-specs-external.md` sebagai spec per halaman.
5. Copy prompt dari `06-prompt-templates.md` ke Stitch.

## Prinsip

- Satu prompt = satu screen. Jangan gabung.
- Selalu lampirkan design system di setiap prompt.
- Bahasa UI: Indonesia.
- Konsisten dengan PRD v3.0.
